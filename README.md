# SQL Practice

Hands-on SQL learning log (PostgreSQL), building towards a data analyst portfolio.

## Contents
| File | Topics |
|---|---|
| week1_session1.sql | SELECT, WHERE, ORDER BY, LIMIT |
| week1_session2_aggregates.sql | Aggregates, GROUP BY, HAVING |
| week1_session3_marketing.sql | Marketing campaign analysis: 15 business questions, data-quality notes, targeting recommendation |
| week2_session1_joins.sql | INNER JOIN, LEFT JOIN, anti-joins, joining lookup tables to the marketing data |
| week2_session2_joins.sql | INNER, LEFT, RIGHT, FULL and SELF joins, anti-joins, FULL JOIN reconciliation |
| week2_session3_case_nulls.sql | CASE, COALESCE, NULL handling, integer division |
| week2_mini_project.sql | `customer_profile` view (age bands, income levels, lookup groups, total spend) and response analysis |

## Datasets
- `campaign_customers`: small practice table (10 rows), created in the Week 1 Session 1 file
- Marketing campaign data (Kaggle, Customer Personality Analysis): 2,240 customers, used from Session 3 onwards
- `customers` and `orders`: small practice tables, created in the Week 2 Session 1 file
- `items_ordered`, `items_received`, `students`, `submissions` and `employees`: small practice tables, created in the Week 2 Session 2 file
- `education_lookup`: maps education levels to groups (Week 2 Session 1)
- `marital_lookup`: maps marital status to groups, created in the Week 2 mini project file

## Tools
PostgreSQL, pgAdmin, GitHub
